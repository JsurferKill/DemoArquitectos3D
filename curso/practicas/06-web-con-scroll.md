# Práctica 6 — Tu propio proyecto publicado

Módulo 6, Web con scroll y publicación (práctica final). Tiempo estimado: entre 5 y 8 horas. Necesitas: tus imágenes y vídeos de un proyecto propio, producidos siguiendo el recorrido de las prácticas 1 a 5.

## Objetivo

Al terminar sabrás montar una web de proyecto cuyo contenido cambia con el scroll, con una ficha de datos final, publicarla con un enlace público y comprobar que funciona en un teléfono. Es el cierre del curso: repites el recorrido completo con tu propio proyecto.

## Punto de partida

Tu propio proyecto: al menos tres imágenes finales en horizontal (como en la práctica 4) y un vídeo corto (práctica 5), más los datos del proyecto. Si aún no tienes uno propio, usa Villa Alba con los archivos de partida de Villa Alba (`curso/villa-alba/superficies.md` y `planta.svg`) para los datos de la ficha.

## Pasos

1. Escribe la estructura de la web en una lista: portada, concepto, imágenes, vídeo, ficha de datos y contacto. Comprueba que cada sección tiene un único mensaje.
2. Prepara los archivos: reduce las imágenes a un ancho de entre 1600 y 2400 px y comprime el vídeo para web. Comprueba que la mayoría de las imágenes pesa menos de 500 KB, que ninguna supera 1 MB y que el vídeo pesa unos pocos megas.
3. Crea la página con tu herramienta de creación web y coloca la portada con título del proyecto. Comprueba que se entiende de qué proyecto se trata sin hacer scroll.
4. Añade las imágenes y el vídeo de modo que cambien o avancen con el scroll. Según tu programa: busca la opción que enlaza el avance del scroll con una imagen, una secuencia o la posición del vídeo.
5. Añade la ficha de datos al final: nombre, localización, superficie construida, parcela, año y autoría. Comprueba que los números coinciden con tu proyecto.
6. Añade un formulario de contacto o, si no es posible, un enlace de contacto. Envía una prueba y comprueba que llega.
7. Publica la web en un servicio de alojamiento y obtén el enlace público. Ábrelo desde una ventana privada del navegador para comprobar que no depende de tu sesión.
8. Prueba la web en un teléfono real: orientación vertical, scroll con el dedo, tiempo de carga y lectura de textos. Apunta lo que falla y corrígelo.
9. Repite la prueba tras los cambios y guarda el enlace final.

## Entregable

Una web con tu proyecto, accesible con un enlace público. La entregas con el enlace, acompañado de una captura de la ficha de datos y otra de la web vista en un teléfono, para comprobar que se ve bien.

## Lista de comprobación

- [ ] El enlace se abre desde otro dispositivo y sin iniciar sesión.
- [ ] Las imágenes o el vídeo cambian con el scroll sin saltos.
- [ ] La ficha de datos contiene al menos seis datos correctos.
- [ ] No hay desplazamiento horizontal en un teléfono en vertical.
- [ ] El texto se lee sin ampliar (cuerpo de 16 px o más).
- [ ] La portada carga en menos de 5 segundos con datos móviles.
- [ ] El formulario o el enlace de contacto funciona.

## Errores frecuentes

- Subir imágenes enormes, lo que hace la web lenta. Lo notas al abrirla con datos móviles.
- Diseñar solo en el ordenador. Lo notas cuando el texto se corta o aparece una barra horizontal en el teléfono.
- Efectos de scroll que impiden leer, con secciones que pasan demasiado rápido. Lo notas al leer el texto una vez.
- Publicar con un enlace que solo funciona en tu equipo. Lo notas al abrirlo desde otro dispositivo.
- Datos de la ficha que no coinciden con el proyecto. Lo notas al compararlos con tu cuadro de superficies.
